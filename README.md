# The Digital Desk

### A personal space to build, experiment, create and document.

The Digital Desk is my personal digital workspace — a place where technology meets creativity.

I'm building this project as a combination of a personal portfolio, creative sketchbook and development journal. It represents my journey as a Computer Science student exploring frontend development, interactive web experiences, motion design and creative technology.

Rather than creating a conventional developer portfolio, I want to build an experience that reflects how I think, what I create, what I'm learning and how my interests evolve over time.

**The idea is simple: a digital space that grows with me.**

---

## ✦ Project Vision

The Digital Desk aims to bring together three important aspects of my journey:

- **Development:** Projects, experiments, technical skills and things I build.
- **Creativity:** UI explorations, motion design, visual experiments and creative work.
- **Documentation:** Learning logs, personal reflections, discoveries and progress.

The long-term goal is to create an interactive, visually engaging and responsive website that serves as both a personal archive and a professional portfolio.

## ✦ Core Sections

The website is planned around five main sections.

### 1. The Desk — Homepage
The main entry point to my digital workspace.

Planned features:
- Personal introduction and current focus.
- Selected projects and creative work.
- Currently exploring section.
- Recent journal entries.
- Links to professional profiles and contact information.

### 2. Showcase — Projects & Creations
A collection of things I've built and experimented with.

Planned categories:
- Frontend and web development projects.
- Full-stack applications.
- AI and technology experiments.
- Motion design and visual compositions.
- Creative coding experiments.

Each project will include its purpose, technologies, development process, screenshots and relevant links.

### 3. Sketchbook — Creative Experiments
A space for visual exploration and experimentation.

This section will document:
- UI/UX explorations.
- CSS animations and interactions.
- Motion design experiments.
- Posters and visual compositions.
- Creative coding and interactive elements.

### 4. Journal — Learning in Public
A personal development log documenting my journey.

It will include:
- Technical concepts I've learned.
- Project development updates.
- Challenges and mistakes.
- Weekly reflections.
- Interesting discoveries and ideas.

### 5. About — The Person Behind the Desk
A little introduction to who I am, what interests me and what I'm working towards.

It will include my background, technical skills, creative interests, resume and contact information.

---

## ✦ Design Philosophy

The visual direction is inspired by editorial layouts, digital notebooks and creative workspaces.

The design will focus on:

- Warm editorial aesthetics.
- Minimalist layouts and generous whitespace.
- Expressive typography and visual hierarchy.
- Paper-inspired textures and subtle details.
- Experimental animations and meaningful interactions.
- Responsive experiences across desktop and mobile.

I want the interface to feel personal, rather than looking like a generic portfolio template.

## ✦ Technology Stack

The project will initially remain lightweight and browser-native.

| Technology | Purpose |
|---|---|
| HTML5 | Semantic structure and content |
| CSS3 | Layout, styling, responsive design and animations |
| JavaScript | Interactions and dynamic functionality |
| Figma | UI/UX design, wireframes and prototyping |
| Git & GitHub | Version control and collaboration |
| GitHub Pages | Static website deployment |

Additional technologies may be introduced as the project evolves.

## ✦ Development Approach

I'm approaching this project as a continuous learning experience.

My process:

1. Research and gather design inspiration.
2. Design interfaces and interactions in Figma.
3. Implement designs using HTML, CSS and JavaScript.
4. Experiment with motion and interaction.
5. Test, refine and optimize.
6. Document what I learn along the way.

I also intend to use this project to strengthen my understanding of frontend development, UI/UX principles, responsive design and motion design.
